# Laptop Store – Product Details & Wishlist

## About
This repository contains my contribution to the Laptop Store project.

## Implemented Pages
- Product Details (`details.php`)
- Wishlist (`wishlist.html`)

## Project Files
- `css/pages/` – Page stylesheets.
- `js/pages/` – Page JavaScript files.
- `js/stores/` – Wishlist data store.
- `api/` – Wishlist PHP API.
- `config/` – Database connection.
- `database/` – MySQL database export.
- `assets/images/` – Product images.

## Requirements
- XAMPP
- Apache
- MySQL
- PHP
- A MySQL database named `laptop_store_db`

## Setup
1. Place the project inside the XAMPP `htdocs` directory.
2. Import `database/laptop_store_db.sql` using phpMyAdmin.
3. Configure the database connection in `config/database.php`.
4. Start Apache and MySQL.
5. Open the project through `http://localhost/laptop-store/`.

## Integration Notes
- Wishlist requires integration with the team's login system.
- Cart functionality requires integration with the team's cart system.
- Verify asset and page paths when merging with the main project.
